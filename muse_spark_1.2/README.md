# Wa-Tor simulations with Muse Spark 1.2
Create a browser-based [Wa-Tor](https://en.wikipedia.org/wiki/Wa-Tor) simulation that emphasizes correct predator-prey cellular automaton behavior.

This project used the model [Muse Spark 1.2](https://artificialanalysis.ai/models/muse-spark-1-2) on 'High' level.  I'm developing with the Visual Studio Code (1.130.0) [chat panel](https://code.visualstudio.com/docs/chat/chat-overview).
