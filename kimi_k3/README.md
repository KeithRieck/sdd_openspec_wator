# Wa-Tor simulations with Kimi K3
Create a browser-based [Wa-Tor](https://en.wikipedia.org/wiki/Wa-Tor) simulation that emphasizes correct predator-prey cellular automaton behavior.

This project used the open-weight model [Kimi K3](https://artificialanalysis.ai/models/kimi-k3) on Medium level.  I'm developing with Visual Studio Code's [chat panel](https://code.visualstudio.com/docs/chat/chat-overview).
