# Wa-Tor simulations with Mistral Medium 3.5
Create a browser-based [Wa-Tor](https://en.wikipedia.org/wiki/Wa-Tor) simulation that emphasizes correct predator-prey cellular automaton behavior.

This project used the open-weight model [Mistral Medium 3.5](https://artificialanalysis.ai/models/mistral-medium-3-5) on 'High' level, developed in France.  I'm developing with the Visual Studio Code (1.130.0) [chat panel](https://code.visualstudio.com/docs/chat/chat-overview).
