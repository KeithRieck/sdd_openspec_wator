# Wa-Tor simulations with Qwen 3.8
Create a browser-based [Wa-Tor](https://en.wikipedia.org/wiki/Wa-Tor) simulation that emphasizes correct predator-prey cellular automaton behavior.

This project used the Chinese open-weight model [Qwen3.8 27B](https://artificialanalysis.ai/models/qwen3-8-27b). I'm running it on 'Medium' level.  I'm developing with the Visual Studio Code (1.134.0) [chat panel](https://code.visualstudio.com/docs/chat/chat-overview).
