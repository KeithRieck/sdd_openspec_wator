# Wa-Tor simulations with Grok 4.6
Create a browser-based [Wa-Tor](https://en.wikipedia.org/wiki/Wa-Tor) simulation that emphasizes correct predator-prey cellular automaton behavior.

This project used the open-weight model [Grok 4.6](https://artificialanalysis.ai/models/grok-4-6-medium) on Medium level.   The 4.6 model was just released, and SpaceX is offering it on discount. I'm developing with Visual Studio Code's [chat panel](https://code.visualstudio.com/docs/chat/chat-overview).
