# Wa-Tor simulations with DeepSeek v4.1 Flash
Create a browser-based [Wa-Tor](https://en.wikipedia.org/wiki/Wa-Tor) simulation that emphasizes correct predator-prey cellular automaton behavior.

This project used the Chinese open-weight model [DeepSeek v4.1 Flash](https://artificialanalysis.ai/models/deepseek-v4-1-flash). I'm running it on 'Medium' level.  I'm developing with the Visual Studio Code (1.137.0) [chat panel](https://code.visualstudio.com/docs/chat/chat-overview).
