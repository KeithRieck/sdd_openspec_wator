# Wa-Tor simulations with Grok 4.5
Create a browser-based [Wa-Tor](https://en.wikipedia.org/wiki/Wa-Tor) simulation that emphasizes correct predator-prey cellular automaton behavior.

This project used the open-weight model Grok 4.5 on High level.  I'm developing with Visual Studio Code's [chat panel](https://code.visualstudio.com/docs/chat/chat-overview).
