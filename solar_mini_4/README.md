# Wa-Tor simulations with Solar Mini 4
Create a browser-based [Wa-Tor](https://en.wikipedia.org/wiki/Wa-Tor) simulation that emphasizes correct predator-prey cellular automaton behavior.

This project used the model [Solar Mini 4](https://artificialanalysis.ai/models/solar-mini4) level.  I'm developing with the Visual Studio Code (1.141.0) [chat panel](https://code.visualstudio.com/docs/chat/chat-overview).
